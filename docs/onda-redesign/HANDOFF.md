# نقل العمل إلى جلسة Claude Code على جهازك

## 1. التحضير (مرة واحدة)
1. فكّ ضغط هذا الملف داخل المشروع:
   `C:\Herd\onda-storage\docs\onda-redesign\`
   هذا المجلد للمرجع فقط، ولن يُدمج في الكود.
2. فعّل git محليًا ليصبح أي تعديل قابلًا للتراجع. لا حاجة لـ GitHub ولا لأي رفع:
   ```
   cd C:\Herd\onda-storage
   git init
   git add -A
   git commit -m "Baseline before ONDA redesign"
   ```
   إذا كان git مفعّلًا مسبقًا، فاكتفِ بعمل commit للحالة الحالية.
3. افتح Claude Code داخل المجلد بإحدى طريقتين:
   - تطبيق Claude Desktop ← Claude Code ← اختر المجلد `C:\Herd\onda-storage`.
   - أو من الطرفية:
     ```
     cd C:\Herd\onda-storage
     claude
     ```

## 2. محتوى المجلد
| الملف | الوصف |
|---|---|
| `auth-preview.reviewed.html` | نموذج الدخول والتسجيل **مع** إصلاحات المراجعة (الخيار أ، وهو ما أنصح به) |
| `auth-preview.html` | النموذج **بدون** إصلاحات المراجعة (الخيار ب) |
| `AUTH-REDESIGN.md` | التدقيق واستراتيجية التصميم والمكوّنات المقترحة |
| `design-system/onda-tokens.css` | ألوان ONDA (فاتح / داكن / تلقائي) بصيغة Tailwind v4 |
| `design-system/useAppearance.ts` | مقترح composable لاختيار المظهر |
| `design-system/brand-preview.html` | معاينة نظام الألوان |
| `design-system/README.md` | قواعد استعمال الألوان |

ملاحظة: النموذجان يستعملان الألوان القديمة. اعتمدهما مرجعًا للتخطيط والسلوك فقط. المرجع الوحيد للألوان هو `onda-tokens.css`.

## 3. الطلب الذي تلصقه في الجلسة المحلية

```
اقرأ أولًا كل ما في docs/onda-redesign/ (خاصة AUTH-REDESIGN.md و design-system/README.md).
المرجع البصري لصفحتي الدخول والتسجيل هو auth-preview.reviewed.html، والمرجع الوحيد للألوان هو design-system/onda-tokens.css.

المرحلة 1 (بدون تعديل أي ملف):
افحص المشروع: مسارات المصادقة، صفحات Auth في resources/js، الـ Controllers و FormRequest وأسماء الحقول الحقيقية وقواعد التحقق، app.css وإعداد Tailwind v4، نظام الترجمة، وهل يوجد useAppearance.
ثم اعرض عليّ خطة: الفروقات بين النموذج والكود، والملفات التي ستُعدَّل، والأسئلة المفتوحة. انتظر موافقتي.

المرحلة 2 (بعد موافقتي):
أضف نظام الألوان (tokens + الأوضاع فاتح/داكن/تلقائي)، ثم أعد تصميم صفحتي الدخول والتسجيل بمكوّنات Vue قابلة لإعادة الاستخدام.
لا تغيّر منطق المصادقة ولا الـ backend ولا قاعدة البيانات ولا المسارات.
احفظ الشعار الرسمي كما هو. واجهة عربية RTL، مع حقول البريد وكلمة المرور والهاتف والأسماء اللاتينية بالاتجاه LTR.

بعد كل مرحلة: شغّل npm run build وفحوصات المشروع المتوفرة، واعمل commit محلي فقط (بدون push).
الشريط الجانبي ولوحة التحكم والنوافذ الحوارية لاحقًا، كل جزء بموافقة منفصلة.
```
