Brand colour system

Light · Dark · System, with every token tested against WCAG 2.2 AA on this page

Blue is the interactive colourButtons, links, focus rings, selection, the active nav item.
Green is a restrained accentSuccess and protected states, small highlights, the second data series. Never the main call-to-action.
The logo is never recolouredOn dark surfaces, or wherever the blue loses contrast, it sits on a white plate.
Spec vs derivedYour palette is used exactly as given. Where a value can't reach AA in a given role, a derived step of the same hue fills that one role.
